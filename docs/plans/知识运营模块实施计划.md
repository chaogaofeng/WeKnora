# 知识运营模块 v1.2 实施计划

> 使用 subagent-driven-development 分工实施，关键路径采用测试驱动；在当前已授权范围内连续推进。

**Goal:** 为启用后的 RAG、Wiki、混合问答提供只读的观测、验证、诊断、分流及人工复核工作台。
**Architecture:** 独立 `internal/knowledgeops` 模块，`capture` 子包定义无持久化依赖的窄接口，原链路只调用接口。模块保存不可变证据与版本化分析，通过数据库任务租约恢复后台执行。前端独立页面和 API，集中注册。
**Tech Stack:** Go、Gin、GORM、PostgreSQL/SQLite、Vue 3、TDesign。
**Spec:** `docs/plans/知识运营模块方案.md`（v1.2，已去除历史适配与回填）。

## 全局约束
- 默认禁用；仅请求开始时已启用的新运行纳入。没有历史扫描与回填。
- 不修改原文、Wiki、FAQ，不注册写工具，不影响问答成功与否。
- 证据部分、未知版本、采集/模型失败如实显示；自动记录不等于人工确认。
- 新数据表使用独立前缀；禁止启动时 AutoMigrate。任务必须持久化、幂等、可恢复。
- 接口遵守现有租户、会话及来源访问规则。不可验证的权限一律拒绝，不通过存储快照绕过撤权。
- 不提交凭据，不使用真实环境数据做示例。全套默认阈值保守，未校准不自动放行。
- 工作区 `/Users/rocky/.codex/worktrees/knowledge-ops-v12/WeKnora`，分支 `codex/knowledge-ops-v12`；不合并或推送用户原分支。

## Task 1: 采集契约和问答薄接入
Files: 新建 `internal/knowledgeops/capture/*.go`；修改 session service、Agent 模型输入与 RAG 模型输入边界；必要 Wiki 来源元数据。
Interfaces: `Sink.Start(context.Context, Start) Recorder`；`Recorder.RecordInput(context.Context, Input)`、`RecordSources(context.Context, []Source)`、`Finish(context.Context, Completion)`、`Gap(context.Context,string)`。接口不返回阻断问答的错误；sink 未注入/禁用时返回 nil。
Start 字段：TenantID uint64；ActorID/SessionID/MessageID/RequestID/Channel/QAType/ExecutionMode/AgentID/ModelID/Question string；StartedAt time.Time。
Source 字段：ID/Kind/KBID/KnowledgeID/ChunkID/PageID/Slug/Version/Content/Title/ToolCallID string；AcquiredAt time.Time；Truncated/SentToModel/PostHoc bool。
Input 字段：Messages []InputMessage；InputMessage 字段 Role/Content/Name/ToolCallID string；不持久化隐藏思维或图片 data URI。
Completion 字段：Answer/Status string（completed/cancelled/failed）；FinishedAt time.Time。
